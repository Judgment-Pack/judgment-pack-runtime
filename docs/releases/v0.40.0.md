# v0.40.0

This release makes the `audit-formats` check stricter for contributors and corrects the
documentation of checkpoint witnesses. Hosts see no change.

## Changes for hosts upgrading from `v0.39.0`

None. No command, output, refusal, persisted byte or digest changes. Persisted audit lines and
dispositions are byte-identical to the ones v0.39.0 writes, and the audit-format catalog, its
change records and `internal/auditformat/status.json` are unchanged.
[CONFORMANCE.md](../../CONFORMANCE.md) is unchanged and states the conformance claim in full.

## Changes for contributors

`go run ./tools/audit-formats` is stricter (#342, #350):

- The released change-record pin, `releasedChanges` in `internal/auditformat/status.json`, must
  cover each file's first change record of its `released` format, and it may hold no record of
  a later format. A pin left behind after a format version moves is refused.
- The persisted evaluation disposition is encoded from `result.CanonicalDispositionShape`, the
  type the check fingerprints, so a new disposition member is a new field there and moves the
  record line's digest. The encoder takes a map only as the top-level `value` member and refuses
  a map member anywhere else, empty or not.

[docs/releasing.md](../releasing.md) describes the pin and the release step that moves it.

## Documentation

- The README and [docs/building-with-packs.md](../building-with-packs.md) said that no gateway
  release served witness statements. They now say that a gateway configured as a witness serves
  them from gateway v0.11.0 on, as the gateway's SPEC §8 specifies; the specification takes the
  statement up in RFC 0017, accepted at draft maturity. `jpack audit verify` reads those
  statements as before.
- The CHANGELOG records that 0.35.0 was never published; its draft was retired and the tag
  `v0.35.0` is kept as history (#344).

## Build

The CI workflow moves to actions/setup-python 7.1.0 (#346), and the release workflow to
docker/login-action 4.7.0 (#345). The release archives, the image and the attestations are built
the same way.

Review records: the pre-release review over `v0.39.0..` is on #351 (a Claude Opus review of a
Claude Opus build; not a cross-vendor claim).
