# Proposed v0.39.0-alpha.2 — release-note draft

This is preparation for a scoped Runtime prerelease supporting Agent v0.11.0.
It records no published Runtime release, immutable RC2 import or completed
adoption/conformance evidence. The final release decision and exact dependency
pins remain pending immutable Spec publication and verification.

The preparation adds a maintainer-only retained-column RC2 archive importer and
independent release checks for imported provenance, complete inventory and the
identity actually selected by CLI/MCP. The importer checks an independently
verified archive digest, exact official repository/tag/source, generated release
identity, reviewed inventory digest and each imported byte against tagged source.
It retains original source paths and records per-file lengths/digests and archive
provenance. It changes no selector or support claim.

No RC2 resources are installed in this candidate. The explicit selected reader
continues to report historical `Draft RFC0029` revision
`ade3914b0b81ef299e5b9a8d6147f37ff3f0976c`. The final import must update this
note to name the actual immutable distribution/source/schema/corpus tuple and
record applicable published-case evidence before claiming selected leaf support.

The role remains document validation and declared pack inventory coverage for
Base and Extended. Raw original document/frame bytes and digests, bounded frame
summary and existing limits retain their contracts. Validation does not establish
producer authenticity, conversion execution, complete preparation verification,
history support or a full-chain Desk cutover. Leaf support does not establish
final Core 0.3.0 conformance.

Before publication, the coordinator owns the frozen import and selector/report
change, compatibility/corpus checks, stable integrated full checklist, exact-head
CI, independent review, whole-release review and existing signed-tag, immutable
release, archive/checksum/attestation and native distribution gates. The next
prerelease version must be checked for availability; this filename reserves none.
