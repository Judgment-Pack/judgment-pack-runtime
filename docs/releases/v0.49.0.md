# v0.49.0

This release hardens the registry line that v0.48.0 added. The emitter host gets a fresh Windows
home, no inherited descriptors, and refusals for reparse-point roots and Windows junctions, and a
write that has begun survives an interrupt. A number-heavy document now costs close to its size
rather than many times its bound. The Terraform reader identifies deposed objects by their keys.
The release also adds a support and deprecation policy for the line, fuzzing of its readers, 90%
coverage floors, and a mutation table that ties every code to the test that catches it.

## For an unchanged pack

For every supported `specVersion` (`0.5.0`, `0.3.0`, `0.2.0-draft`, `0.1.0-draft`), no
disposition, evaluation output, decision record byte or digest differs from `v0.48.0`. Comparing
the `v0.48.0` release binary with this release's build:

- **Conformance runs.** For each selector, with and without `--strict`, `spec test-conformance
  --format json` gave the same bytes apart from the tool's version.
- **The evaluation corpora.** For `0.2.0-draft`, `0.3.0` and `0.5.0` (20, 20 and 103 cases),
  `experimental evaluate-corpus --format json` gave the same bytes apart from the tool's version.
- **Spec validation.** On each of the 2709 JSON documents of Spec `v0.6.0`, `spec validate` gave
  the same exit code and the same output.

The changes a caller may notice are all in the registry line, the Terraform reader and the
start-up module, and are listed below.

## What is new

- **The emitter host's environment and root** (ADR-0098).
  - On Windows the emitter gets `TEMP` and `TMP` under its fresh home, and `USERPROFILE`,
    `APPDATA` and `LOCALAPPDATA` at it. None of the parent's values is passed.
  - On Unix every descriptor above 2 is marked close-on-exec before the first emitter starts.
  - A `--root` that passes through a junction or another reparse point is refused with its own
    message, not resolved.
  - `jpack emit` no longer starts the emitter with SIGPIPE ignored.
- **Interrupts.**
  - `jpack emit` interrupted before its write refuses the run (`EMIT-PROCESS`) and writes nothing.
    A write that has begun finishes, and a second signal ends `jpack` at once, except during that
    write.
  - `jpack emit conformance` interrupted is refused with `EMIT-HARNESS-BOUND`, and drops the
    interrupted vector's rows.
- **Staging leftovers.** A `.jpack-emit-*` staging file that a stopped run left, which no owns glob
  matches, is reported by the new provisional warning `EMIT-STAGING-LEFTOVER` and never deleted.
- **One link check.** Every check that refused only a final symbolic link (the gate summary, a
  saved continuation, a published manifest, a conformance suite root and each component of a
  fixture path, and the file opens) now refuses a Windows junction too.
- **Bounds.**
  - A given `request.json` is bounded by its canonical size.
  - A vector's directory and its `expected/` are listed under bounds on their entries. In
    `expected/`, files and directories are now bounded separately, so a valid record of 7000 files
    nested two directories deep is read.
- **Cost** (#458). Admission compares a number with its double's shortest decimal without big
  arithmetic. A canonical form is measured before it is built, wherever it is held to a bound. A
  64 MiB request of `1e20`s took 16.7 GB of allocation and about 40 seconds before it was refused;
  allocation is now about 75 times the bound in all, and admission about 58 times the input.
- **Terraform** (dialect §4.5 step 4). A deposed object is identified by its address and key, and
  the acquired value is sorted by id. A key that is not a non-empty string, or two resources with
  one id, is `TF-DOCUMENT`. `TF-VALUE-LIMIT`'s message names both of its bounds.
- **Options schemas** (#459). An emitter's options schema may use `$defs` at its root.
- **The registry line's policy** (VERSIONING.md). Within major version 1 of the line, nothing is
  removed, no bound is tightened, additions come under new minor selectors, and a deprecated part
  keeps working. It takes effect from the release that names the line stable. That release has not
  happened, so every registry-line code stays provisional. An emitter's own `x-` codes belong to
  that emitter.
- **Testing.** A scheduled workflow fuzzes the registry's reference readers, the start-up module,
  and the YAML, Terraform and dialect readers. The registry line's packages are held to 90%
  statement coverage. A mutation table (docs/registry-mutation-table.md) records, for each code, the
  test that asserts it and a mutant that test kills, and a check keeps it complete.

## Changes a caller may notice

- **Options-schema `$defs` below the root.** A `$defs` one level below an options schema's root,
  under `items`, `not` or `additionalProperties` for example, was admitted by v0.48.0 by mistake.
  It is now `EMIT-MANIFEST` at its pointer, as the kind subset requires.
- **Terraform batches with a deposed object.** Each deposed object now has its own batch line id,
  `<address> deposed <key>`, and its `deposed` member. Before, it shared its current object's id.
- **Start-up module.** `ReadFile` refuses a world-writable file under every rule.
  `ReadResolvedFile` refuses a file that is not regular without blocking on it. `ErrNotRegular`'s
  text changed; match it with `errors.Is`.
- **Windows.** A conformance suite or fixture path that passes through a directory reparse point,
  such as a synced folder's placeholder directory, is now refused.

## Decisions

No ADR changes status in this release. ADR-0096, ADR-0097, ADR-0098 and ADR-0103 are amended in
place.

The release review ran as one clean room over the whole diff (same vendor, not a cross-vendor
claim). It found one HIGH and no MEDIUM. The HIGH was a refusal the CHANGELOG did not state, the
options-schema `$defs` one level below the root; the code was right, and the CHANGELOG now states
it. The low-severity findings are carried in #468 for v0.50.0. Omitting an outward link that git
does not track, which #450 asked for, is #467, also for v0.50.0. Until then, the harness refuses
every outward link, as before.
