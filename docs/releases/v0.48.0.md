# v0.48.0

This release adds `jpack emit`, a host that runs registry emitters, and `jpack emit conformance`,
a harness that checks emitters against their vectors. It also adds three reference emitters (Go
typed facts builders, a Go typed loader, and TypeScript constants), a start-up module that reads a
resolved registry and delivered secrets, and `jpack terraform facts`, which turns a Terraform plan
or state into a facts batch.

## For an unchanged pack

For every supported `specVersion` (`0.5.0`, `0.3.0`, `0.2.0-draft`, `0.1.0-draft`), no
disposition, evaluation output, decision record byte or digest differs from `v0.47.0`. Comparing
the `v0.47.0` release binary with this release's build:

- **Conformance runs.** For each selector, with and without `--strict`, `spec test-conformance
  --format json` gave the same bytes apart from the tool's version.
- **The evaluation corpora.** For `0.2.0-draft`, `0.3.0` and `0.5.0` (20, 20 and 103 cases),
  `experimental evaluate-corpus --format json` gave the same bytes apart from the tool's version.
- **Spec validation.** On each of the 2709 JSON documents of Spec `v0.6.0`, `spec validate` gave
  the same exit code and the same output.

The exceptions are in the registry commands. They read a few inputs differently, to follow the
registry companion's text:

- A kind declaration's step-2 diagnostics now carry `kind` in their location.
- A schema's cycle check covers every `$ref` that names a definition, whatever else the schema
  fails.
- An entry reference's `#pointer` is held to 512 code points, not 512 bytes.
- An `id` is read as an RFC 3986 `absolute-URI` by the runtime's own reader. Non-ASCII and
  characters outside RFC 3986, which `net/url` admitted, are now refused.
- A pattern's size is counted on the pattern as written. For example, `(ab|ac){1000}` is now
  `REG-KIND-PATTERN-LIMIT`.
- `FACTS-DOCUMENT-LIMIT`'s message begins "A facts document". The code and the limit are
  unchanged.

## What is new

- **`jpack emit`** (ADR-0098; spec RFC 0036 §§1–4) runs an emitter that its manifest names.
  - It forms an RFC 8785 request from a registry, or from facts contracts, holding only the kinds
    the manifest reads. A request is at most 64 MiB.
  - It runs the emitter from the repository root with a minimal environment and a fresh `HOME`,
    under a time limit that ends the emitter's whole process group.
  - An interrupt (Ctrl-C or `SIGTERM`) ends the emitter's process group the same way, and removes
    its temporary directories.
  - Every response is validated whole before anything is written: owned, safe, case-fold-unique
    paths within size bounds.
  - `--check` compares the response with the files on disk and writes nothing.
  - A resolved-form request carries the read kinds' declarations, bound to their pins by digest
    (ADR-0101).
- **`jpack emit conformance`** (ADR-0099; spec RFC 0036 §5) runs an emitter on its author's
  vectors through the host's own steps.
  - Level `1.0` has six checks: golden equality, determinism, path safety (29 hostile responses),
    kind filtering, references, and no stray writes.
  - `--update` rewrites `expected/` atomically.
  - CI runs it over this repository's reference emitters on every change to them.
- **Three reference emitters**, each with its own vectors in RFC 0036 §5's layout:
  - `cmd/jpack-emit-go-facts` (ADR-0100; RFC 0037 §6) writes Go typed facts builders, with a
    `Decimal` that is never a `float64`.
  - `cmd/jpack-emit-go-loader` (ADR-0102; RFC 0036 §6 item 1) writes a Go typed loader. Secrets
    are typed `startup.Secret` and read lazily.
  - `cmd/jpack-emit-ts-constants` (ADR-0103; RFC 0036 §6 item 2) writes TypeScript types and
    read-only constants for each environment, leaving every secret position out of both.
- **A start-up module, `startup/`** (ADR-0096; RFCs 0034 §8 and 0035), is a separate Go module
  under a 1.0 promise, with no dependency outside the standard library.
  - It reads one environment's resolved registry and the secrets the platform delivered. It never
    contacts a secret store.
  - A value is held in `Secret`, which never prints.
  - The module is tagged `startup/v0.1.0`, separately from the runtime.
- **`jpack terraform facts`** (ADR-0097; spec RFC 0038) writes one batch line per selected
  resource of a plan or a state. It uses a reader that removes every value marked sensitive before
  selection.

The `REG-*`, `FACTS-*`, `TF-*` and `EMIT-*` codes that the released companions do not name are
provisional (VERSIONING.md).

## Decisions

ADR-0096 to ADR-0103 move from proposed to accepted with this release.

The release review ran as two clean rooms over the whole diff (same vendor, not a cross-vendor
claim). It found no HIGH and three MEDIUMs, all fixed before the tag in #451:

- an interrupt left the emitter running;
- on Windows, a repository root that is a junction was scanned as empty;
- the Go loader refused a registry at the depth bound.

The low-severity findings are carried in #450 for v0.49.0.
