# v0.39.0

This release completes the v0.39.0 milestone. It ships the work first cut in the scoped
prereleases `v0.39.0-alpha.1` (MCP owner taxonomy and method skills) and `v0.39.0-alpha.2`
(the selected retained-column leaf at Spec `v0.3.0-rc.2`). It moves both onto the published
[Spec `v0.3.0`](https://github.com/Judgment-Pack/judgment-pack-spec/releases/tag/v0.3.0), and it
adds fingerprints for the audit trail's persisted line formats.

## Changes for hosts upgrading from `v0.39.0-alpha.2`

- **The selector changes.** Automation that selects the retained-column leaf must use
  `retained-column/1@27cb29bf13e4a2d58d69fe19c7ebfeb762b014fc`. The candidate selector
  `retained-column/1@bcac15b7537ce21879201b5e5dfe795496225121` now refuses. The flag and field
  names are unchanged: `--draft-contract` and `--draft-profile` on the CLI, `draftContract` and
  `draftProfile` over MCP.
- **Text that named the candidate.** CLI help, CLI output and MCP strings no longer say "RC2".
  A host that matched on that text must match on the selector instead.
- **The reader page moved.** It is now [docs/dialect-retained-column.md](../dialect-retained-column.md).
- Reports still name maturity `draft`. Final Spec publication is not an evaluator-conformance
  claim; [CONFORMANCE.md](../../CONFORMANCE.md) states that claim in full.

## Audit line-format fingerprints (#327)

A new check, `audit-formats` (`go run ./tools/audit-formats`), fingerprints the shape of every
persisted audit line type. That includes the evaluation disposition, whose members are now declared
and checked against the writer's own output. A writer change that alters a persisted shape
fails the check until its format-status record names the change. Released change records are
pinned and may only be appended to. The fingerprint covers shape, not value encodings or
timestamp spellings. Persisted audit lines are unchanged in this release. The check's
remaining gap, a future member written only on some branches, is tracked in #342.
